# Generated diagrams

This directory contains the retained upstream MIT notice for the adapted timeline and flowchart composition ideas. The project does not copy Kami's static diagram catalog. `scripts/diagrams.py` generates the two supported SVG types from structured Markdown, using this project's Geist default and neutral/blue visual system. See `references/template-editing.md` for the editing map and `references/examples/long-document-diagrams.en.md` for input examples.
