# Generated diagrams

This directory contains the retained upstream MIT notice for the adapted timeline, flowchart, quadrant, layer-stack, and swimlane composition ideas. The project does not copy Kami's static diagram catalog. `scripts/diagrams.py` generates these SVG types from structured Markdown, using this project's Geist default and neutral/blue visual system. See `references/template-editing.md` for the editing map and `references/examples/visual-catalog.en.md` for input examples.
