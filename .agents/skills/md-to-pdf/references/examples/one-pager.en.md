# Project Atlas

A clear plan for improving the onboarding experience in one focused quarter.

## Opportunity

New users need a simpler first session and clearer guidance for their first task.

In this synthetic scenario, the first-run path presents several choices before the user has completed a meaningful action. The team wants to learn which choice causes uncertainty and whether clearer wording helps.

## Approach

- Review current onboarding flows.
- Test a shorter path with a small group of users.
- Measure completion and comprehension.

The study would use one consistent task scenario, a short observation guide, and a review of the current help text. Findings would link back to notes rather than claim a product-wide effect.

## Outputs

| Artifact | Purpose |
| --- | --- |
| Task map | Show where decisions occur |
| Observation notes | Preserve what participants did and said |
| Test proposal | Define one small follow-up change |

## Next step

Approve a two-week discovery sprint.

The decision is limited to discovery. A product change would require a separate review of evidence, effort, and expected benefit.
