# Editing templates and components

Edit Markdown fixtures in `references/examples/` to change example content. Edit `references/design.md` when changing the documented design rules. Template CSS and HTML are the visual sources; renderer scripts map validated Markdown to those sources. Rebuild the fixture gallery after a change and review every affected PDF page.

| Document | Visual source | Structure and rendering |
| --- | --- | --- |
| Plain document | `assets/plain-document.css` | `scripts/build-document.py` |
| Proposal | `assets/document.html`, `assets/tokens.css` | `scripts/build-proposal.py` |
| Résumé | `assets/templates/resume-ats.html` | `scripts/parse_resume.py`, `scripts/render_resume_html.py`, `scripts/build-resume.py` |
| Cover letter | `assets/templates/cover-letter.html` | `scripts/render-cover-letter.py` |
| One-pager | `assets/one-pager.css` | `scripts/build-one-pager.py` |
| Long document | `assets/long-document.css` | `scripts/build-document.py` |
| Portfolio | `assets/portfolio.css` | `scripts/portfolio_content.py`, `scripts/build-document.py` |
| Analytical report | `assets/report.css` | `scripts/report_content.py`, `scripts/build-document.py` |
| Changelog | `assets/changelog.css` | `scripts/changelog_content.py`, `scripts/build-document.py` |
| Pitch deck | `assets/deck.css` | `scripts/build-deck.py` |

`scripts/style_profile.py` defines the global default font and colors. `scripts/build.py` routes the selected Template and applies eligible profile overrides. `assets/geist-latin.woff2` is the bundled default font. The résumé keeps its own visual contract and does not accept profile overrides.

Charts and metric displays are generated by `scripts/charts.py`; timelines, flowcharts, quadrants, layer stacks, and swimlanes are generated by `scripts/diagrams.py`. Their styling is completed by the report, long-document, and deck stylesheets. The diagram folder contains provenance and license information rather than a static SVG catalog because geometry is generated from the Markdown data. Adding another diagram type requires a data contract, renderer, tests, and human visual review.

Run `python3 .agents/skills/md-to-pdf/scripts/gallery.py --output output/fixture-gallery` after editing a visual source. The saved HTML files in that output are the review surfaces used to render the PDFs. Generated output stays outside Git.
