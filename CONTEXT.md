# Markdown to PDF

Vocabulary for documents produced by the `md-to-pdf` skill.

## Language

**Pitch deck**:
A narrative presentation made of slide-sized pages and delivered as a PDF.
_Avoid_: PPTX, web page

**Template**:
A document-type layout that determines the structure and presentation of a PDF output.
_Avoid_: Style guide

**Style guide**:
The project's rules for visual consistency across templates, including typography, color, spacing, and print behavior.
_Avoid_: Template

**Style profile**:
A user's saved global choices for font, accent color, and paper color; an explicit document request can override them.
_Avoid_: Template, style guide
